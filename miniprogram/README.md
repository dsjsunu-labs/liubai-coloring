# 留白 · 微信小程序版

[留白 · 填色实验室](../README.md) 的原生微信小程序版本。用 WXML / WXSS + Canvas 2D 重做，不加载外部网页，也不需要配置业务域名。

## 打开

1. 打开微信开发者工具 → **导入项目** → 选择本目录（`liubai-coloring/miniprogram`）。
2. `project.config.json` 里的 AppID 是 `touristappid`（游客模式），可以直接编译预览；正式发布时换成你自己的小程序 AppID。
3. 编译后点「预览」生成二维码，用有权限的微信扫码体验。
4. 上传代码后，由管理员在小程序后台提交审核、发布。预览二维码不等于正式发布。

## 已迁移功能

- 28 套配色，每套 8 色，按 OKLab 明度排序；切换套装保留作品的色阶。
- 碎片、彩绘玻璃、数字填色、像素拼豆四种模式；会话中切换模式保留各自作品。
- 点按 / 拖动填色、橡皮、撤销 / 重做、清空、重切、单块切割。
- 碎瓷、柔弧、锯齿、圆弧四种切法，可调密度与边缘变化。
- 一键铺色、从选中区域向邻接碎片传播的漫填，以及带折面明暗的展开动画；动画可关闭。
- 微信原生相册 / 拍照导入；提取八色，按连续色区与玻璃网格生成可填碎片。
- 大理石、宝石、像素、玻璃、方块、水流六种程序化质感，以及无纹理选项。
- 方形原作 1600 × 1600、手机壁纸 1320 × 2868、iPad 竖屏 2064 × 2752 / 横屏 2752 × 2064，通过原生接口保存相册。
- 当前作品与设置自动保存在本机；撤销栈在会话内保留。

## 结构

```text
miniprogram/
├─ app.js / app.json / app.wxss
├─ project.config.json
├─ pages/index/index.js     页面、触摸、撤销、相册、导出
├─ pages/index/index.wxml   原生界面
├─ pages/index/index.wxss   流式布局
├─ utils/engine.js          配色、几何、分区、命中、切割、邻接传播
├─ utils/renderer.js        Canvas 2D 绘制与程序化质感
└─ assets/materials/        大理石 / 宝石 CC0 贴图与许可
```

没有生产依赖，不需要构建 npm。基础库 3.7.0，使用 Canvas 2D 节点。

## 注意

- 这是小程序版本，需要微信开发者工具；网页版在仓库根目录，双击 `index.html` 就能玩。
- 使用相册 / 拍照 / 保存图片前，需要在微信后台配置对应的用户隐私保护指引。
- 作品与图片识别都在本机处理，没有服务端上传。
